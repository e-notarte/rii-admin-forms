Welcome to the Admin Portal

Your centralized hub for efficient request management and precise administrative tracking.

How to use this Portal

Access the Navigation Menu

Click the three-line (hamburger) button in the top left corner to reveal the navigation panel. This panel is hidden by default to give you a clean, distraction-free workspace.

Submit & Manage Requests

Use the navigation menu to access various request forms such as Vehicle, Conference Room, or Supplies. This system ensures precise recording and logging of all company requests.

Monitor Dashboards

Track request statuses, calendar reservations, and inventory in real-time through the dedicated Admin and Supplies dashboards.
